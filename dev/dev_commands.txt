# 🛠️ Developer Commands for Dayli Project

This document contains commonly used developer commands categorized by technology.

---

## 🐙 Git Commands
```bash
# Clone repository
git clone git@github.com:your-org/dayli.git

# Check status
git status

# Create and switch to new branch
git checkout -b feature/new-ui

# Push code to origin
git push origin feature/new-ui

# Pull latest changes
git pull origin main

# Kdiff3 as command
git config --global merge.tool kdiff3
git config --global mergetool.kdiff3.path "C:/Program Files/KDiff3/kdiff3.exe"
git config --global mergetool.kdiff3.trustExitCode false

git config --global diff.tool kdiff3
git config --global difftool.kdiff3.path "C:/Program Files/KDiff3/kdiff3.exe" --replace-all
git config --global difftool.kdiff3.trustExitCode false


```

## 🧱 Laravel / PHP Artisan
```bash
# Migrate fresh with seeding
php artisan migrate:fresh --seed

# Serve Laravel backend
php artisan serve

# Run tests
php artisan test

# Generate model with migration and controller
php artisan make:model Models/Product -mcr

# Seed address table
php artisan db:seed --class=AddressSeeder

# Clear caches;
php artisan cache:clear;php artisan view:clear;php artisn optimize:clear;php artisan route:clear; php artisan config:clear; php artisan config:cache


# Dayli - set zone=1 for products.
 php artisan dayli:bootstrap-zone-products --zones=1


php artisan shopify:pull-products


```

## 🐬 MySQL / DB
```bash
# Login to MySQL
mysql -u root -p

# Import SQL dump
mysql -u root -p dayli_db < delivery_actuals.sql

# List databases
SHOW DATABASES;
```
